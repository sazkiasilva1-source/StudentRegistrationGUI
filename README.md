Form Pendaftaran Mahasiswa
Program ini merupakan aplikasi sederhana berbasis Java yang dibuat menggunakan GUI untuk menampilkan form pendaftaran mahasiswa.
Fitur Program
- Mengisi nama mahasiswa
- Mengisi NIM
- Memilih jurusan
- Menyimpan data pendaftaran
- Mengosongkan form menggunakan tombol Reset
Komponen Utama GUI yang Digunakan
JFrame digunakan sebagai jendela utama aplikasi untuk menampilkan seluruh komponen GUI.
JPanel digunakan sebagai wadah untuk mengelompokkan komponen GUI agar susunannya lebih teratur.
JLabel digunakan untuk menampilkan teks keterangan seperti Nama, NIM, dan Jurusan.
JTextField digunakan sebagai tempat memasukkan data nama dan NIM mahasiswa.
JButton digunakan sebagai tombol untuk menjalankan perintah, yaitu Simpan dan Reset.
